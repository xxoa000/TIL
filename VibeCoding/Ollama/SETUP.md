## Ollama 란?
무료로 사용 가능한 오픈 로컬 AI.  
외부로 데이터가 전달되지 않기에 개인용, 프라이버시용으로 많이 사용하며, 인터넷 없이도 사용 가능하다.  
내부 RAM 용량을 사용하며 CPU,GPU 를 이용하여 연산한다.

`https://ollama.com/`  
사이트에서 운영체제에 맞는 버전을 다운로드 받는다.  
파일을 설치한 후 로그인 없이 바로 실행이 가능하다.  
<br>
`ollama run qwen2.5:7b`  
터미널에서 해당 명령어를 입력한다. 나는 qwen2.5:7b 모델을 선택했다.  
Qwen2.5 모델은 최대 18조 개의 토큰을 포함하는 알리바바의 최신 대규모 데이터셋으로.  
이 모델은 최대 128,000개의 토큰을 지원하며 다국어를 지원한다.  
7b 는 모델의 크기로 소형에 속한다. (최소 RAM 은 8GB / 권장 RAM 은 16GB / 속도 빠름)
