# 파이토치 설치
python3 -m pip install torch : 
  터미널에서 해당 명령어로 파이토치 설치.
  mac 에선 자체 파이썬도 설치되어 있어 파이썬 버전이 여러개이기 때문에
  pip install torch 가 아닌 python3 -m pip 명령어를 사용하여 어떤 파이썬에 설치할 것인지를 지시함.

## 파이참(IDE) 설치
공식 다운로드 사이트 https://www.jetbrains.com/pycharm/download/?section=mac
.dmg (Apple Silicon) 버전 다운로드 -> PyCharm 아이콘을 Applications 폴더로 드래그.

  ### 파이참 설치 후 설정 조정
  Pycham -> 설정 -> Python -> 인터프리터 -> (+) 버튼 누른 후 torch 검색 -> 패키지 설치.
