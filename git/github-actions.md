# GitHub Actions로 프로필 README 자동 업데이트

- schedule로 주기적으로 실행할 수 있다.
- workflow_dispatch로 수동 실행할 수 있다.
- API 토큰은 코드 대신 GitHub Secrets에 저장한다.
- 파이썬으로 README의 지정된 주석 사이만 수정한다.
